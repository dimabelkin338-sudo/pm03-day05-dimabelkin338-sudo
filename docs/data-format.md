# Формат данных бронирования аудиторий

## Описание полей (7 полей контракта)

| Поле | Тип данных | Обязательное | Описание |
| :--- | :--- | :--- | :--- |
| `id` | String | Да | Уникальный идентификатор бронирования (UUID) |
| `room_number`| String | Да | Номер аудитории |
| `owner` | String | Да | ФИО или логин забронировавшего пользователя |
| `date` | String | Да | Дата бронирования в формате YYYY-MM-DD |
| `time_start` | String | Да | Время начала бронирования (HH:MM) |
| `time_end` | String | Да | Время окончания бронирования (HH:MM) |
| `status` | String | Да | Текущий статус (`confirmed`, `pending`, `cancelled`) |
